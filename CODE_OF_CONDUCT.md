# Code of Conduct

Wir erwarten einen respektvollen, sachlichen und inklusiven Umgang. Belästigung,
Diskriminierung, persönliche Angriffe und das Veröffentlichen privater Informationen
werden nicht toleriert.

Projektverantwortliche dürfen Beiträge moderieren oder entfernen, wenn sie diesen
Grundsätzen widersprechen. Vorfälle können vertraulich über die in `SECURITY.md`
beschriebenen privaten GitHub-Kanäle gemeldet werden.
