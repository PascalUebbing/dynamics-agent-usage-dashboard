# Security

Sicherheitslücken bitte nicht als öffentliches Issue melden.

Nutzen Sie GitHub Private Vulnerability Reporting im Repository. Geben Sie betroffene
Version, reproduzierbare Schritte, Auswirkung und bekannte Workarounds an. Entfernen Sie
Mandantendaten, Tokens, Connection IDs und personenbezogene Inhalte aus dem Bericht.

Unterstützt wird die jeweils aktuelle Release-Linie.
