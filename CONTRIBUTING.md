# Contributing

Beiträge sind willkommen.

1. Issue für größere Änderungen eröffnen.
2. Branch erstellen und Änderungen klein sowie nachvollziehbar halten.
3. `npm run typecheck`, `npm run lint`, `npm test` und `npm run build` ausführen.
4. Keine Mandanten-IDs, URLs, Exporte, Gesprächsinhalte oder Zugangsdaten committen.
5. Neue Kennzahlen mit einer reproduzierbaren Microsoft-Datenquelle und einer klaren
   fachlichen Definition dokumentieren.

Solution-Komponenten müssen aus `solution/src` reproduzierbar paketierbar bleiben.
Umgebungsspezifische Werte gehören in Connection References oder Environment Variables.
